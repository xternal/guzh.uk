Questions

Fair questions.

Why someone from outside defence?

Because the problems after a raise are the same in every fast-growing company: too much to do, too few people, and processes built for ten staff carrying a hundred. Defence adds rules on top; it doesn't change the arithmetic. You bring the defence know-how; I bring having done the scaling, hands-on.

Is this a consultancy?

No decks. I do the work: the supplier tracker, the hiring pipeline, the internal tool, the bid pack. What you get is software and processes that run differently the following week.

Do you need a security clearance?

Not for the unclassified work, which is where this sits. Where a task needs vetting, we say so at the start and agree who does it and how.

What size of company is this for?

UK defence and dual-use companies (drones, counter-drone, autonomy, defence AI, space, advanced manufacturing) from about 15 to a few hundred people, usually just after a funding round or a first contract.

Is the GitHub activity on this page real?

Yes. Your browser asks GitHub's public API for my public activity when the page opens and shows counts, repository names and dates, nothing else. If GitHub is busy, the log simply links to the profile.
